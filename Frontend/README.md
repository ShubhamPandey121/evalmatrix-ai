# EvalMatrix AI - Frontend Web Client 🚀

> **Developed by Shubham Pandey (<shubham230884@gmail.com>)**  
> GitHub: [ShubhamPandey121](https://github.com/ShubhamPandey121)

This is the client-side single page application for **EvalMatrix AI**, built using React 19, Vite 7, Sass, React Router 7, and Axios.

## 🛠️ Features

- **Live Interview Practice Lab:** In-browser mock interview answering with a countdown timer, speech synthesis audio prompts, and real-time AI scoring.
- **ATS Resume Downloader:** One-click dynamic ATS-friendly resume export.
- **Career Roadmap:** Interactive 7-day preparation schedule with checklist persistence.
- **Interactive Match Analysis:** Visual breakdown of technical strengths, skill gaps, and match percentage.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Production build
npm run build
```
